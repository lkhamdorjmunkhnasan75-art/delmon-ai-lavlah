# Synthetic identity and isolation
Offline HS256 JWT fixture issuer only (not a production OIDC implementation). Strict issuer, audience, subject, signature, iat/expiry (max 300s), unique jti and claim allowlist. No discovery or real identity service. Dedicated restricted identity login resolves subject to user UUID, sets transaction-local identity and existing RLS role; profile endpoint returns own user and organizations only. Revocation persisted by jti and serialized with token use. Pilot DB checks actual database, session login, privileged role flags, server address and marker on same connection. Explicit pilot mode required at Next proxy; production directory fails closed when LAVLAH_ENV=production. Existing shared-code pilot chat remains separate, not identity-backed; no production identity or tenant mutation API. Legacy unspecified-mode public directory remains for regression tests. DB marker is a configuration guard, not proof of physical network isolation. Trusted DB service credentials must never reach clients; RLS GUC is not safe against arbitrary SQL by that service. Real OIDC/JWKS, issuer key rotation, account lifecycle, revocation cleanup, full role management, mandatory deployment mode for all processes, network isolation and independent review remain release gates. Migration 010 rollback/reapply and disposable backup/restore row data and selected ACL checks passed. npm audit reported zero vulnerabilities.
