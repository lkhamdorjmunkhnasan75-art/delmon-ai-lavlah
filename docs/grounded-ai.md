# Offline grounded AI pilot
POST /v1/pilot/grounded-ask requires both LAVLAH_ENABLE_PILOT_QA=1 and LAVLAH_ENABLE_MOCK_AI=1. Use isolated synthetic DB only. Existing bounded Mongolian interpreter retrieves at most 20 public rows, validates expiry and source, ranks exact/prefix/shorter names and keeps five unique candidates. The mock adapter can select only up to three allowed IDs; server renders original fields, never adapter prose. Invalid selection or exception uses deterministic fallback. No model calls or source fetching. Mock units count characters, not real tokens; synthetic rates 2 and 5 micro-MNT per input/output unit. Actual charge always zero. Unknown failed usage is null, not zero. Numeric usage returned and emitted at INFO without question or identifiers; configure log collection separately, no durable ledger or actual provider pricing. No production exposure; auth, rate limits, hard deadline for future real adapters, independent evidence quality, actual token accounting, persistent metrics and UI remain release gates. Expected 84 distinct tests plus backup/restore; CI must pass before completion.
