# Mobile pilot chat
Existing Next.js PWA root includes Mongolian chat. Enable only in isolated test environment: LAVLAH_ENABLE_PILOT_CHAT=1 on Next server; LAVLAH_ENABLE_PILOT_QA=1 and LAVLAH_ENABLE_MOCK_AI=1 on FastAPI, using disposable synthetic DB. Same-origin POST proxy accepts bounded JSON, forwards only to numeric loopback, rejects redirects and times out upstream after 8 seconds. Client timeout 10 seconds, single in-flight request, retry, clear/abort, up to 20 in-memory turns, React text rendering and safe HTTP(S) source links. Source dates shown in Ulaanbaatar time. Feedback is local to current chat, not persisted or submitted. No live AI, real source fetch or real payment. No conversation context sent to backend; each question independent. Production authentication, CSRF/host configuration review, rate limits, persistent feedback with consent, real device testing and human pilot remain gates. Expected 89 distinct tests plus backup/restore. CI pending.
