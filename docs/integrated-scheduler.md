# Integrated scheduler
Run python -m lavlah.scheduler in an operator-controlled environment with LAVLAH_INGESTION_DSN and LAVLAH_FEED_DIR. Network is off unless LAVLAH_ENABLE_HTTPS=1 is explicitly set; only registered enabled permissions and jobs are eligible. Do not activate until reviewed. The integrated entrypoint excludes registered HTTPS permissions from local collection. Do not run the legacy standalone collector or direct HTTPS function in parallel in production.
 
The scheduler reserves a persistent run with a 120-second lease, fences stale writes, recovers expired runs and retries after 15 minutes. Shared exact-host request slots enforce 60 seconds between reservations in addition to per-permission limits. The worker process limits network transport to 20 seconds plus startup/termination overhead; tests use offline fixtures. Run statistics are private aggregate counts, not unique records or an external monitoring service. Failed attempts have sanitized codes. Crash after commit but before scheduler completion can lead to interrupted status and replay rejection; source provenance stays intact. Host aliases and shared registrable domains are not consolidated. Source timestamps remain publisher assertions. Independent egress controls, authentication, deployment, OS process supervision, actual TLS integration and monitoring alerts remain production gates. No live requests or scheduler activation performed.
