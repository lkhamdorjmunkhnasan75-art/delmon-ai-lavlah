# Synthetic pilot environment
Only use a disposable PostgreSQL database named lavlah_pilot_test on numeric loopback, with the migrated schema and database marker ALTER DATABASE lavlah_pilot_test SET lavlah.pilot_only='yes'. Use a dedicated local test cluster, separate credentials, and LAVLAH_PILOT_ONLY=1. Set LAVLAH_PILOT_DSN to the disposable database administrator DSN and LAVLAH_PUBLIC_DSN to a separate restricted reader in that database.
Run python -m lavlah.pilot_fixtures seed or reset. The four synthetic organizations have explicit ТУРШИЛТ labels and reserved example.test URLs; two are visible, one unapproved, one expired. No external requests. Reset removes fixture rows, retains shared categories, and refuses unexpected users, organizations or sources. Never copy real data into the pilot. CI builds the schema without data into a new DB and destroys it afterwards. Guardrails are not a substitute for cluster isolation or separate credentials; no public deployment. Cyrillic substring search only; Latin transliteration and AI answers are later work.
