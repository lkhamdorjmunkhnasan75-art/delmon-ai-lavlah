# Authorized HTTPS adapter
Administrator registers a disabled endpoint tied to an existing permission and enables it only after documented approval. Exact HTTPS endpoint must match the permission URL. GET only, port 443, no credentials, query, redirects or proxies. All resolved addresses must be public; connection uses a validated numeric address and TLS checks the original hostname. JSON envelope has updated_at (timezone-aware timestamp) and records (1–100 public-field objects). Body limit 512000 bytes. Per-permission durable request reservation precedes I/O; failed fetches consume their slot. After fetch, permission is checked again, timestamp bounded by freshness policy and monotonically increasing, hash and timestamp recorded, candidates require human review. No automatic publication.

Use collect_registered only from trusted internal code; tests inject offline transport. The source timestamp is an assertion from the HTTPS publisher, not independently signed proof. Registry administration, authenticated actor binding, network egress firewall, aggregate per-host limits, hard whole-request/DNS deadlines, crash-attempt reconciliation, scheduler integration and production penetration testing remain gates. No live endpoints registered or accessed. Existing local scheduler remains separate and must not be used to refresh a registered HTTPS feed. No API tokens supported.
